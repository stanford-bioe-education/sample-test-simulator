Sample and statistical test simulator

This is a simulation to demonstrate the impacts of sample size and the assumptions you make about your data. Edit the parameters below and then click Generate samples to randomly generate samples of your chosen size from the true population distribution and effect size. Observe how the results of different statistical tests compare and contrast. Clicking Generate samples repeatedly will generate new random samples.

Setup

Group A always uses the baseline parameters below. Group B (and C, if selected) use the same distribution family, shifted by the effect size you choose — measured in units of Group A's own spread, so it means roughly the same thing across distributions.
